# BijakDigital - Website Solusi Dampak Informatika

Website statis interaktif yang membahas berbagai dampak negatif perkembangan teknologi informatika (keamanan data, sosial, dan kesehatan) beserta solusi praktis untuk mengatasinya.

## Fitur Utama
1. **Katalog Dampak & Solusi Interaktif**: Dilengkapi filter kategori (Keamanan Data, Sosial & Informasi, Kesehatan Digital).
2. **Kalkulator Kesehatan Screen Time**: Membantu pengguna mengevaluasi durasi penggunaan gawai harian mereka.
3. **Kuis Literasi Digital**: Latihan singkat untuk menguji kewaspadaan terhadap keamanan siber dan kesehatan digital.
4. **Mode Gelap (Dark Mode)**: Mendukung kenyamanan membaca di berbagai kondisi pencahayaan.
